\# Simple ATM Simulator



\## Description

My seventh C programming project.



This program simulates a simple ATM system. Users can check their balance, deposit money, and withdraw money through an interactive menu.



\## Features

\- Start with a balance of $1000.00

\- Check the current balance

\- Deposit money into the account

\- Withdraw money from the account

\- Prevent negative or zero deposits and withdrawals

\- Prevent withdrawals that exceed the available balance

\- Repeat the menu until the user chooses Exit

\- Handle invalid menu options



\## Example Output



```text

=== Simple ATM ===

Current balance: 1000.00



1\. Check Balance

2\. Deposit Money

3\. Withdraw Money

4\. Exit



Choose a number of option: 2

How much do you want to deposit: 250

Deposit successful!

Your new balance: 1250.00

```
