\# Personal Introduction



\## Description

My first C programming project.



This program asks the user for their name and age. It then asks whether they want to see their age in five years.



\## Features

\- Read the user's name and age

\- Display a personalized greeting

\- Calculate the user's age after five years

\- Use Y/N input to control the program



\## Concepts Practiced

\- Variables and data types

\- Input and output (`scanf`, `printf`)

\- Conditional statements (`if`, `else`)

\- Basic arithmetic operations



\## Language

C
