\# Number Counter



\## Description

My fourth C programming project.



This program asks the user to enter a positive integer, displays all numbers from 1 to the entered number, and calculates their sum.



\## Features

\- Accept an integer from the user

\- Display numbers from 1 to the entered number

\- Calculate the sum of all displayed numbers

\- Handle zero and negative numbers



\## Example Output



```text

Enter the number: 5

Number: 5

Numbers: 1 2 3 4 5

Sum: 15

```



\## Concepts Practiced

\- Integer variables (`int`)

\- User input with `scanf()`

\- Output with `printf()`

\- `for` loops

\- Conditional statements (`if`, `else if`)

\- Accumulation using `+=`



\## Language

C
