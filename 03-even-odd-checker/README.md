\# Even or Odd Checker



\## Description

My third C programming project.



This program asks the user to enter an integer and determines whether the number is even or odd. It also handles zero and negative numbers.



\## Features

\- Accept an integer from the user

\- Determine whether the number is even or odd

\- Handle positive and negative integers

\- Display a special message when the number is zero



\## Example Output



Enter the Number: 8



8 is an even number.



\## Concepts Practiced

\- Integer variables (`int`)

\- User input with `scanf()`

\- Formatted output with `printf()`

\- Conditional statements (`if`, `else if`)

\- Modulo operator (`%`)

\- Comparison operators (`==`, `!=`)



\## Language

C
