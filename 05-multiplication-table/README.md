\# Multiplication Table



\## Description

My fifth C programming project.



This program asks the user to enter an integer and displays its multiplication table from 1 to 10.



\## Features

\- Accept an integer from the user

\- Generate a multiplication table from 1 to 10

\- Calculate the product for each multiplier

\- Display results in a readable format



\## Example Output



```text

Enter the number: 7

7 \* 1 = 7

7 \* 2 = 14

7 \* 3 = 21

7 \* 4 = 28

7 \* 5 = 35

7 \* 6 = 42

7 \* 7 = 49

7 \* 8 = 56

7 \* 9 = 63

7 \* 10 = 70

```



\## Concepts Practiced

\- Integer variables (`int`)

\- User input with `scanf()`

\- Formatted output with `printf()`

\- `for` loops

\- Multiplication operator (`\*`)

\- Assignment operator (`=`)



\## Language

C
