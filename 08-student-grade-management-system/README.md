\# Project 08 — Student Grade Management System



\## Description

A simple C program that manages grades for five students.



\## Features

\- Stores five student grades using an array.

\- Validates grades between 0 and 100.

\- Allows users to retry when a grade is out of range.

\- Displays all entered grades.

\- Calculates the average grade.

\- Finds the highest and lowest grades.



\## Concepts Practiced

\- Arrays

\- For loops

\- Do-while loops

\- Conditional statements

\- Input validation for numeric grade ranges

\- Basic calculations



\## Known Limitation

The program does not handle non-numeric input correctly.



\## Language

C
