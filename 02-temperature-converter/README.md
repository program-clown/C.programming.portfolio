\# Temperature Converter



\## Description

My second C programming project.



This program converts temperatures from Celsius to Fahrenheit and displays the result with two decimal places.



\## Features

\- Accept temperature input in Celsius

\- Convert Celsius to Fahrenheit

\- Display the result with two decimal places

\- Show a freezing warning when the temperature is below 0°C



\## Formula



F = (C × 9 / 5) + 32



\## Concepts Practiced

\- Variables and data types (`double`)

\- User input with `scanf()`

\- Formatted output with `printf()`

\- Conditional statements (`if`, `else`)

\- Arithmetic operations

C
