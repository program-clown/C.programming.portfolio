\# Number Guessing Game



\## Description

My sixth C programming project.



This program generates a random number between 1 and 20. The player must guess the number, receiving hints after each incorrect attempt.



\## Features

\- Generate a random number between 1 and 20

\- Accept guesses from the player

\- Display "Too low!" or "Too high!" hints

\- Repeat until the correct number is guessed

\- Count the total number of attempts



\## Example Output



```

=== Number Guessing Game ===

Guess the number (1-20): 5

Too low!!!

Guess the number (1-20): 15

Too high!!!

Guess the number (1-20): 12

Correct! You guessed the number!

Attempts = 3

```



\## Concepts Practiced

\- Integer variables (`int`)

\- User input with `scanf()`

\- Conditional statements (`if`, `else if`, `else`)

\- `while` loops

\- Random number generation using `rand()` and `srand()`

\- Using `time()` to seed the random number generator

\- Counting attempts
